# 你认识我的时候，我才15岁 — 第三版电脑端制作稿

本轮变更与明确的验收边界见 `V3-NOTES.md`。第三版已改为分层Canvas、八方向逐帧步行、约两倍移动速度、网格寻路和六个重绘场景；以下为保留的第二版基线记录，不代表第三版现状。

独立的静态校园漫游网页。第一版保持不变。

## 已实现

- 连续 1080 × 1476 逻辑坐标的校园，默认 8 倍近景；世界 SVG 标称尺寸 8640 × 11808。
- 40 处建筑、625 棵矢量树、球场、跑道、湖、桥、路灯、长椅。17 个可进入的入口。
- 原角色正面、背面、侧面；WASD / 方向键移动；建筑、水域、树干碰撞。
- 手机使用 2160 × 2952 的校园优化图与按需室内图，避免解析巨型 SVG；点击道路可自动行走，方向键用于微调，并显示下一站方向。
- 鼠标拖动镜头不移动玩家；滚轮缩放；空格回到玩家；M 展开右上角小地图。
- 原片头视频（可长按跳过），宿舍床上的第一人称睁眼，再起身漫游。
- 宿舍、饭堂、教室三类室内。物件、对话、课桌近景。NPC 沿道路往返。
- 按访问次数向前推进六个时段；第三次饭堂出门才转傍晚；第三次教学楼进入夜晚。
- 夜晚窗户和路灯变化；宿舍洗漱、查寝、睡觉；合眼完成后黑屏 30 秒，再从床上醒来。
- 轻环境音，可关闭。无精力、卡牌、收集惩罚、强制结局和私人彩蛋。

## 素材依据与边界

- 校园布局依据用户上传的标注校园地图。建筑是依据地图位置重建的示意外观，并非逐栋测绘。
- 角色、教室、床上视角、课桌和视频源自用户已有素材。
- 新宿舍、饭堂、树木按用户已有画风参考生成，再转换为真实 SVG 路径。
- 矢量描摹消除了位图放大插值，但不恢复原图不存在的细节。不能把 SVG 尺寸当成原生 2K 图像细节或画风完全一致的证明。
- 室内有纹理色块化，户外建筑的造型多样性仍有限；画风尚需用户对照原作验收。
- 人物行走为方向切换与轻微摆动，还不是独立绘制的完整逐帧步态。
- 32 位路人目前复用同一角色轮廓，并非独立人物设计。
- 可进入的不同建筑共用对应类别的室内；没有为每栋建筑虚构专属真实室内。
- 场景文字区分《最坏的时光》原文摘意和校园日常补写；不引入私人彩蛋。

## 文件

- `dist/` 是全部交付网页，无第三方 CDN、网络追踪或外部运行时依赖。
- `dist/world-data.js` 维护地点、道路、碰撞与时段规则。
- `scripts/build-world.mjs` 生成世界 SVG 和树干碰撞数据；生成后运行测试。
- `scripts/trace.py` 是可选的 VTracer 转矢量工具，需安装 vtracer。
- `scripts/test.mjs` 是非浏览器的 JSDOM / Node 逻辑检查；通过 `JZ_TEST_DEPS` 指定 jsdom 安装路径。

## 验证

已检查 JavaScript 语法、所有部署素材路径、SVG 无内嵌位图、17 个入口的碰撞网格可达性、键盘行走、拖动镜头而人物不动、从床起身、完整六次访问、时段不回退、夜间洗漱重置、30 秒闭眼循环。

已离线渲染并目检人物、树木、室内和校园局部；未在真实浏览器中进行端到端或设备性能测试。
